PRIVACY POLICY

JPEG Vice

Effective date: 3 September 2026

JPEG Vice is developed and published by Boris Hurinek.

Information JPEG Vice processes

JPEG Vice accesses only the JPEG image files that the user selects for processing, either directly or by selecting a folder containing JPEG images. The images are processed locally on the user's device solely to reduce their file size while preserving their resolution and image properties.

JPEG Vice does not collect, upload or transmit images, image information, usage information or other personal information. It does not contain advertising, analytics or third-party behavioural tracking.

If an image cannot be processed, JPEG Vice may write an error log beside the affected image. The log remains on the user's device and is not transmitted.

Data processing and sharing

All image processing is performed locally on the user's device. JPEG Vice does not upload or transmit images, image information or usage information, and does not sell or share personal information with third parties.

The user controls which images are processed by choosing the files or folders passed to JPEG Vice.

If the user chooses the optional website link in JPEG Vice, the website is opened in the user's default browser. No image or usage information is passed to the website by JPEG Vice.

Changes to this policy

This policy may be updated if JPEG Vice's features or data practices change. The effective date above will be updated when a revised policy takes effect.
